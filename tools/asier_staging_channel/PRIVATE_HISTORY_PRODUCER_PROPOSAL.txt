Implemented prerequisite

ordered object replies, requires canonical ASCII '<sha1> blob <size> LF', exact

Proposed next implementation, before any actual-object run
1. Accept an explicitly reviewed local Git object repository and trusted Linux
   Git executable. No repository URL, clone, fetch, provider credentials, shell,

   Read back executable identity/digest for the exact runner; record supported

   git --no-lazy-fetch --no-replace-objects --no-optional-locks --no-pager
       -c safe.directory=<reviewed-local-repository>
       -c core.hooksPath=/dev/null -c core.fsmonitor=false

   No --filters, --textconv, --follow-symlinks, revision/path expressions or
   caller object substitutions. Only pinnedHistoryRequestV1 goes to stdin.
   Exact executable invocation has no shell; repository and executable paths

   Repository configuration/alternates/local storage and the runtime executable
   remain explicit trust inputs; missing promisor objects must block, never fetch.

   stderr is discarded, never console forwarded or retained. Stream/process

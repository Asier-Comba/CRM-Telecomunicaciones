## Interpretation

Every row retains the old capability or gives an explicit domain/security reason. Decision and delivery state are independent. Final verification is recorded in W2_STATUS; source implementation alone is not browser acceptance. IMPLEMENTED refers to the preview UX and does not mean a production backend is connected. Synthetic read-mode and local draft interactions never count as real writes. File index records every source file; large old pages are reference material, not imported as new monoliths.

## Audit baseline and delivery definitions

Inventory complete at source level; old browser screenshots unavailable in this session. UI parity is not accepted on compile/route existence alone. Baseline preview has 6 limited read screens; no billing, company configuration, inbox or automation parity. Delivery states now record explicit scope: SYNTHETIC_IMPLEMENTED and LOCAL_IMPLEMENTED are functional preview UX, PARTIAL is incomplete behavior, BLOCKED has a concrete contract dependency, NOT_IMPLEMENTED records missing UI, and PRESERVED_BACKEND records unchanged platform work. None implies production acceptance. Metrics and executed evidence are maintained in `agents/W2_STATUS.md`.

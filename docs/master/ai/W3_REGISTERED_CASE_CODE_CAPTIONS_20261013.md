# Registered Case codes in readable Spanish

The product's existing eight resolution/cancellation captions are shared through
a pure typed presentation module. Case forms retain their current wording and
stored command values. The assistant's registered-code columns now display
both the original code and its Spanish caption, for example
`entered_in_error · Registro incorrecto`. Null stays null.

This changes presentation only. It does not alter current W1 parsers, services,
permissions, selected-customer scope, notes/privacy, filtering, commands,
authority, factual evidence or persisted conversation content. The table and
source still describe registered state; a resolution code is not independent
confirmation. Portability already uses its existing Spanish reason labels and
is retained. No screen or new executable capability is added.

Existing Case read/privacy/role/absence/revocation/seam tests, global types and
changed-file lint validate the correction. A local synthetic full DTO/plan/read/
response probe covers resolved/cancelled/empty codes and original-code retention.
It is not a live-model or actual Auth/DB measurement. Full controls on the new
published SHA remain necessary; prior1298/340/native/Supabase results cannot
transfer. IA writes OFF, release NOT_ACCEPTED and five HIGH remain open.

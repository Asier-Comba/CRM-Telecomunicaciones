# W2 physical execution admission

`assistant_durable_v1_start_execution(uuid,text,text,text,bigint)` atomically moves a current original actor's audited reservation from `reserved` to `executing`, increments its exact version and starts a DB-owned five-minute execution lease. The current membership/writer authority is locked inside the transaction. Full binding and expected version are checked before the transition; the authoritative clock is captured after the operation, registered command/catalog, original audit/delivery and effect outbox locks. Expiry during a blocking outbox lock cannot admit execution.

This is lifecycle admission only. It does not claim a worker, return a claim fence, invoke a handler, authorize an external effect, produce arguments/results or enable routes. The outbox remains pending, unclaimed and unchanged; the original immutable reservation audit/delivery remains unchanged. Actual effect execution requires the separate current worker/fence claim and reviewed registered argument/resource authorization, which are still missing. The registered dispatcher catalog remains empty in production; all test registrations are disposable synthetic fixtures.

An original-actor lookup, exact binding, live lease, registered command/dispatcher association and original reservation audit/delivery are mandatory. Foreign actor/tenant, revoked authority, stale or exhausted version, already started operation, claimed/delivered outbox, expired reservation and unaudited legacy association are rejected. A lost successful reply can be recovered by the authorized persisted lookup; retrying the old expected version conflicts and cannot restart the lease.

The typed six-method constructor uses fresh server-owned authority, closed RPC strings and the named persisted projection. A success must have exact successor version, executing state, original binding, no receipt/failure and exactly five minutes between persisted update and lease end. It cannot be used as effect authority. No public/anon/authenticated/service_role grants are introduced. The other five of eleven methods and production session wiring remain pending; issue10 OPEN, writes OFF, full23 NOT_RUN and independent W4 acceptance required.

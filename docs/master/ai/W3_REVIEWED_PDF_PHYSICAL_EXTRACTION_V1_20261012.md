# Reviewed PDF physical extraction adapter

This unit implements an optional extraction adapter for the existing document-source admission boundary. It uses a configured absolute Python interpreter and the fixed local `extract-reviewed-pdf-v1.py` worker with pinned pypdf6.10.0. No provider call, shell, Storage URL, input filename or model-selected interpreter/script is accepted. Provider/CRM credentials are excluded from the child environment. No default production activation or assistant read registration is added.

The worker accepts bytes on stdin, checks the exact PDF header and10MiB input limit, rejects encrypted PDFs and more than100 pages, parses strictly with bounded root-object recovery, keeps finite8MiB stream expansion limits and emits only closed sequential page/text JSON. Aggregate extracted text is capped at200KB and wire output at220KB. The parent retains its10s maximum wall-time bound, input copy, strict UTF8/schema checks, cancellation and owned-process termination. A JSON reply alone cannot pass before observed zero close. Parser warnings/errors are suppressed and mapped to one safe category. These are process/parser bounds; an OS memory sandbox and independent W4 security acceptance remain pending.

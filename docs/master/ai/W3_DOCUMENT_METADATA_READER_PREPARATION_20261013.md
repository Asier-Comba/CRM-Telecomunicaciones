# Bounded customer document metadata reader

The preparatory reader accepts only `document.list` for an explicitly selected customer, active/archived status and a private keyset, with default/maximum20 rows. Caller target kinds/IDs, workspace fields, search text and indexing flags are refused before scope resolution. It maps the owned customer input to the existing W1 `DocumentServiceV1.list`; only current owner/admin membership can reach that service's RPC. No service-role client, new SQL, permission, ticket, upload, download or resource is introduced.

The projection validates the complete existing W1 DTO, its selected target, state, order, unique IDs and pagination before retaining only internal document ID, registered kind/status, MIME and nullable size. It drops version and target. Private filename/path/URL/content additions invalidate the DTO instead of being silently admitted. Metadata does not prove available PDF bytes, verified integrity, review, indexing permission, extraction, complete descendant inventory or operational RAG.

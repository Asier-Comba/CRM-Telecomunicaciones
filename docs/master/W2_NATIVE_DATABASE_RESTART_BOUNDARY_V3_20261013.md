Extends the existing W2 consumer of the unchanged W5 resource. The private inspector reads PostgreSQL system identifier, measured postmaster start and the actual persisted operation binding from the owned `telecom_test` database before and after restart. It requires exactly one completed operation at the supplied server-owned workspace/ref and rejects a foreign actor, capability, digest, missing/duplicate row or extra payload. Scope is captured before the first await; baseline/inspection are one-shot and errors stay closed.
